# Cloth adapter contract

- Preparation owns the pinned Three.js r132 Verlet simulation, one 24-second warm-up, eight continuous 24-second playback banks, one exact simulation checkpoint per bank, source topology, camera transform, texture sampling, sparse lighting and fog rows, fixture geometry, directional shadow projection, and the single ground-plane transform.
- Runtime may only select the desktop or mobile prepared profile once from the 600px media query, fetch that profile's fixed Morph package resources concurrently, select one cryptographically random starting bank, and expand the selected checkpoint in the bank Worker into exact cloth and shadow transforms. The main thread mounts the prepared Morph package after the first four seconds of matrices arrive, consumes the remaining bounded response chunks in idle slices, retains the active bank plus one fully Worker-prepared successor, publishes prepared transform, shadow, and atlas-row state, and updates the single responsive perspective carrier. Safari-family browsers mount the exact prepared projective ground `matrix3d()` without a user-agent rejection and use the prepared `<s>` atlas fallback with one static canonical triangle clip while retaining fixtures, lighting, shadows, playback, and stable DOM. Publication never advances beyond the materialized prefix, derives geometry, rasterizes, reconstructs DOM, or allocates strings per frame.
- Preserve the source defaults: 10 by 10 cloth cells, 25-unit rest distance, 0.03 damping, 0.1 mass, 981 times 1.4 gravity, 18 ms squared Verlet integration, structural constraints, wind enabled, the full top row pinned, and the ball hidden.
- The desktop retained graph uses 200 `<u>` corner-shape cloth triangles and 51 moving cloth-shadow leaves. The mobile profile bilinearly remeshes the same prepared source simulation to a full 6 by 6 square with 72 cloth triangles and 25 moving shadow leaves. Both profiles use source Lambert shading and Three.js r132 linear fog baked into exact-deduplicated opaque RGB prepared atlas rows, 30 static shadow leaves for the two poles, top bar, and two feet, one quality-45 AVIF direct-image ground leaf whose pinned grass texels are inverse-mapped from source world UVs into the PolyCSS projective homography with the source texture's default `flipY`, a prepared anisotropic mip filter capped at 16 samples, a fitted depth-varying phase correction, source Lambert shading, and Three.js r132 linear fog baked into the pixels, and solid quad leaves for the fixtures. Apart from the static canonical clip on the prepared `<s>` triangle fallback, there is no runtime background tiling, Canvas, WebGL, WebGPU, SVG scene geometry, mask, runtime polygon construction, runtime atlas rasterization, or DOM growth.
- Keep source checkouts, captures, and generated prepared assets ignored.
- Do not claim pixel parity without a fresh pinned-source frame sequence and browser diff.
